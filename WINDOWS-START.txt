VYRNSPIRE 0.32.0 — WINDOWS x64

Extract all files and open Vyrnspire.exe beside Vyrnspire.pck. Keep exported DLLs beside them.
WASD/arrows: move. Mouse: aim. Left click/Space: attack. Right click/Shift: dodge.
1/2/3: spells. Q: class skill. E: interact. C: camp. I: gear. M: map.
V: Survival supplies. B: spellbook. Escape: pause/back. F11: fullscreen.
Start-Low-Power.bat selects safe settings; Start-OpenGL.bat selects native OpenGL.

Formerly Runebound. Existing Windows characters/settings remain in
%APPDATA%\Godot\app_userdata\Runebound Godot. Keep that historical folder.
Public application branding is VYRNSPIRE; the fixed old data path preserves your existing saves.
Android uses the same original package/signing identity for updates.
Pause > Export character save produces VYRNSPIRE-Character.json; old JSON exports still import.
Camp > nearby Storage > Choose supplies to store or take adds selective transfers.
Physical Windows executable startup, drivers/audio and sustained performance still need testing.

Ash and Oath: after claiming Chapter I, speak with Mara in the Story journal. Complete the Emberforge sword + magic trial (prior wins count), read its inscription, defeat the Keeper and both embers, then return to Mara. Android/Windows use the same quest logic.

Crowd Relief: Reduced crowds defaults ON, capping ambient wilds population at 6. Pause > Enemy crowds offers Standard (12). The frame cap is separate. Story/trial/dungeon objectives retain their enemies.

Fieldcraft: all regional resource nodes and three story camps have distinct shaded artwork. Same art and gathering/quest behavior on Android and Windows. The atlas SVG and its deterministic generator are editable in the source.

Settings → Controls offers the shared layout editor. Keyboard/mouse and gamepad continue independently. Gamepad hiding is optional. Hardware gamepad/native Windows tests remain pending.

HIDDEN DEPTHS: Camp > Quests > Explore Glacier Hollow / Oathstone Mine. Follow the marked branch trails to ENTER. Read the journal, open the mechanism and defeat the guardian; an optional watchman protects one-time treasure. Entrance stairs always leave. Gold stairs leave after the main guardians fall.

WAYKEEPER BEACONS: Camp > Waykeeper beacons. Track a shrine; read its oath, interact with the three stones in order, return to awaken watchers, then claim its Epic relic. E interacts. Progress persists; unfinished fights can be retried.

DUNGEON ATLAS: M opens the current dungeon floor. Select Entrance or a discovered destination for a gold route. World map toggles outdoors; Current dungeon floor returns. Escape/Resume exploration returns to play.

CHAPTER III: Camp > Chapter III. After Chapter II, accept at Mara, investigate the two swamp records, finish the Veil Altar trial, reclaim Blackmire, and backtrack to its level-two archive for the Drowned Testament. Return to Mara for the chapter reward. Earlier site/trial/boss progress counts.
