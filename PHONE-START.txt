RUNEBOUND — ANDROID EDITION — GODOT 0.12.0
===========================================

THIS GITHUB REPOSITORY IS FOR THE ANDROID GAME.

PLAY (installed APK):
- Keep the existing Runebound Godot app and its saved data.
- To apply a newer APK, it must use the same app package and signing certificate.
- Do not uninstall or clear data when updating.
- This repository contains editable project source; cloning it does not install the game.

EDIT THE GAME ON YOUR PHONE:
1. Install the official Godot 4 Android editor, compatible with Godot 4.5.x.
2. Download/clone the repository.
3. Import project.godot.
4. Open the project and use the editor's Play button.
5. Edit scenes, scripts and touch controls; save/commit changes to GitHub.

PHONE CONTROLS:
- Joystick: move; ATTACK: melee or weapon attack; DASH: dodge.
- Fire / Frost / Heal: spells; class-skill button: unique ability.
- Camp: building, crafting, cooking, gardens and trading.
- Pause: orientation, low-power mode, sound, auto pickup and saves.
- Auto pickup collects nearby resources; chests and gardens are interactive.

THE ANDROID BUILD:
- Android export preset only; package ID app.runebound.godot.
- ARM64, version code 19, Godot 4.5.x matching templates + Android SDK + JDK 17.
- Private signing key is NOT provided in the public GitHub repository.
- New keys generally prevent installing over the original app while retaining its data.

SOURCE SNAPSHOT:
- v0.12.0 editable game; Android focused.
- v0.13.0 has not been uploaded; hunger/thirst/sleep survival is a future addition.
- No APK build was produced as part of switching the repository to Android.
