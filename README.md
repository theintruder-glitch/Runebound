# Runebound

Runebound is an original offline fantasy survival RPG for Android and Windows, built with Godot and GDScript.

## Development snapshot

The latest editable project archive recovered for this repository is **v0.12.0 (Laptop Edition)**. The full source code has **not yet been pushed** to this repository. Do not treat this README-only initialization as a buildable checkout. Changes mentioned after v0.12.0 need to be merged when newer source becomes available.

Current project features include exploration across four regions, character classes and hidden-class unlocks, combat and spells, camps and construction, crafting, hunger/thirst/sleep survival systems, weather, inventories, and automatic resource pickup.

## Requirements

- Godot 4.5 or newer
- Android SDK, Java JDK, and Android export templates for APK builds
- A local Android signing key (not stored in this public repository)

Once source is uploaded, open `project.godot` in Godot to edit the game.

## Security

Never commit `*.jks`, `*.keystore`, passwords, personal save files, or Android signing credentials. Keep the existing prototype signing key offline: losing it can prevent updates to previously installed APKs.
